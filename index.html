The open regulatory interface underneath the portals.

OpenPermit is the reference implementation of Open Regulatory Infrastructure (ORI): a permissionless, vendor-neutral substrate for governments, practitioners, software and models to inventory, publish, traverse, verify, measure and challenge regulatory processes.

This is the current ORI/OpenPermit project in corelotorg/OpenPermit — not the legacy 2016 OpenPermit API or the real-estate phrase “open permit.”

Cold clone. Validate. Run.

A stranger should not need a meeting to determine whether the contract is real. These commands exercise schemas, negative semantic controls, the precedence engine and the MCP reference node.

git clone https://github.com/corelotorg/OpenPermit.git cd OpenPermit python -m pip install -r conformance/requirements.txt -r reference-node/requirements.txt python conformance/validate.py python -m pytest -q reference-node/test_graph.py python reference-node/smoke.py python reference-node/server.py

One real jurisdiction, with sources and gaps.

The first jurisdiction inventory maps published residential-new-construction process evidence for the City of Fredericksburg, Virginia. It records authorities, application inputs, selected fees, inspections, appeal context and a simplified precedence slice while explicitly listing what remains incomplete.

Authority

Virginia + City enforcement

State code adoption and local enforcement are separately addressable and sourced.

Application

Published inputs

Site plan, soils form, land-disturbance/E&S artifact, contractor/licensing data and construction value are represented as published evidence.

Fees

Effective schedule

Selected residential fees are encoded with amounts/rates, effective date and the City source.

Inspections

Non-exhaustive by design

The City itself says the published inspection list is incomplete, so the profile preserves that gap instead of manufacturing completeness.

Process graph

Precedence, not fiction

A simplified DAG exposes the documented sequence while warning that parcel-specific zoning, utilities, environmental and land-development approvals are not yet complete.

Appeal

Challenge path

The inventory preserves the published local-board then Virginia SBCTRB appeal context without asserting outcomes.

Conformance must prove it can fail.

JSON matching a schema is necessary, not sufficient. The harness now includes negative semantic fixtures that must be rejected.

Mapping-as-fact → rejectNormalized mapping semantics must live in a MappingAssertion.
Guidance-as-law → rejectGuidance authority cannot be silently serialized as a binding Requirement.
Challenge mutation → rejectA challenge cannot rewrite the object it challenges.
Cyclic PrecedenceGraph → rejectA graph declared as precedence must actually be acyclic.
Inspect negative fixturesInspect reference node
Boundary: structural or semantic conformance does not prove legal correctness, jurisdictional applicability, professional authority or regulatory approval.

A concrete federal implementation target.

The HUD 2026 profile converts State and Local Best Practices for Home Construction into computable controls, evidence and measurements. It is federal guidance — not silently promoted to binding local law and not an endorsement of OpenPermit.
